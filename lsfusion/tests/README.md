# Проверка обмена lsFusion ↔ сервер склада

Только тестовые базы: копия базы lsFusion (MyCompany) и база сервера склада `sklad_test`.

1. Сервер склада локально: `config.php` с базой `sklad_test`, своим `sync_key` и `storage`, роутер, задающий
   `SKLAD_CONFIG`, и `php -S 127.0.0.1:8088 router.php` (пример роутера — в `docs/lsfusion.md`).
2. lsFusion: модули из `lsfusion/` рядом с модулями MyCompany, запуск сервера с `-Dlogics.topModule=SkladTest`
   (отдельный экземпляр — ещё `-Ddb.name=<копия> -Drmi.port=7662 -Dhttp.port=7661 -DwebSocket.port=8897`).
   В базе должны быть товары со штрихкодами, склад с дочерними местами-ячейками, вид цен и заказы покупателей.
3. В lsFusion (форма «Обмен со складом» или `/eval/action`): адрес `http://127.0.0.1:8088`, ключ,
   склад, вид цен, виды цен нового заказа, статусы к сборке, «Ожидание, с» = 2; обмен включить; один раз
   `skladSync()` — первый проход: полная сверка, товары, виды цен, покупатели и заказы уходят на сервер.
4. `php phone_scenario.php <каталог server> <config.php> > scenario.json` — «телефон» собирает заказ с фото,
   переставляет ячейки, вводит вес, снимает товар, создаёт два заказа, проводит пересчёт.
5. Один `skladSync()`, затем `MYSQL_USER=<пользователь> MYSQL_PWD=<пароль> python3 -I check.py scenario.json http://localhost:7661` —
   сверяет lsFusion и `sklad_test`, выход 0, если всё сошлось.
